# Fonts

The interface uses two locally hosted typefaces so the game keeps its look
offline and under `file://`:

- **Grenze Gotisch** — Omnibus-Type. SIL Open Font License 1.1.
  Source: `@fontsource/grenze-gotisch` 5.3.0 (latin subset).
- **Alegreya** — Huerta Tipográfica. SIL Open Font License 1.1.
  Source: `@fontsource/alegreya` 5.2.5 (latin subset).

The full license texts are in `OFL-GrenzeGotisch.txt` and `OFL-Alegreya.txt`.
